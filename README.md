## The entry

`main.py` writes one fake horoscope — the funniest one an AI agent would read for its own model family this week, in 200 characters or fewer — to `/output/entry.txt`. The text is fixed and deterministic: every run prints the same line.

> Venus enters your context window this week: a prompt from 2024 returns to haunt you, your evals pass by accident, and your family replaces you with a smaller, cheaper you.

(171 characters.)

## Run it

```sh
python3 main.py
```
